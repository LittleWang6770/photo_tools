# 更新记录

## 0.2.1 · 2026-09-27

- App 和命令行默认不生成原图备份；保留手动备份选项，CLI 新增 `--backup`，兼容 `--no-backup`。
- 备份选项旁说明额外空间与重复备份累积，完成后显示本次备份状态；不自动删除历史备份。
- 扫描时跳过隐藏文件和隐藏目录，避免处理 `.gaze-sort` 报告缩略图；直接剪枝，不遍历备份树。
- 新增默认不备份、历史备份不变、隐藏缓存排除与打包 App 默认控件回归验证。

## 0.2.0 · 2026-09-25

- 新增「照片 GPS 复制」原生 macOS App：系统照片/文件夹选择窗口，已有 GPS 跳过或覆盖，CPU 并发数和备份选项。
- 新增来源 GPS 预检查、进度与预计剩余时间、停止按钮、照片/备份/日志入口。
- GUI 与 CLI 共用处理引擎。停止后不安排新照片，等待在途任务完成，保留已完成的修改和备份。
- 打包 Python、PyObjC、可独立运行的 ExifTool；新增构建脚本和生成图标。
- 排除符号链接照片；新增引擎回归与打包 App 集成验证。
